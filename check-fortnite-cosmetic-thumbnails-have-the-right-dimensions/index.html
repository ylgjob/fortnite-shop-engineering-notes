Check Fortnite Cosmetic Thumbnails Have the Right Dimensions

November 24, 2026

A catalog can serve different thumbnail sizes to phones and laptops. An oversized or stretched thumbnail can slip into a grid without anyone noticing during a release.

Start with one square source image, one tall source, and one very small source. Ask the thumbnail job for two output widths. Record the actual width and height of each result. If you crop for a square frame, decide which part of the image should stay in view. If you scale instead, check that the proportions are kept.

Pick a grid in the SkinRotation cosmetic catalog as a reference for the shape and size cards use. Then test a missing image alongside the three working inputs. It should produce a clear placeholder or a recorded error without preventing the other thumbnails from being built.
