Test Fortnite Shop Cache Revalidation With an ETag

November 26, 2026

A browser can ask whether the shop has changed since its last visit. It sends the ETag from the previous response. If the server confirms the same content, the browser can reuse its saved copy without downloading the whole page.

Request a page and keep its ETag. Send it back in If-None-Match. If the server supports revalidation and the content is the same, expect a 304 with no page body. Now change one offer in a test environment. With the old tag, expect a fresh response and a different tag.

Use a public page like the Fortnite Item Shop on SkinRotation to choose a realistic test URL. Check the server response before judging what the browser shows, since developer tools can display a cached page even when the response body was empty.
