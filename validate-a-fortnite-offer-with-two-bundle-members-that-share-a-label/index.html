Fortnite Shop Engineering Notes

Validate a Fortnite Offer With Two Bundle Members That Share a Label

November 24, 2026

Two cosmetics can look interchangeable in a quick fixture if they share a display label. A bundle parser that keys members on name may then silently drop one. That changes both the card count and the destination a player gets after selecting a member.

Define membership with stable identity

Store the bundle offer ID and a list of member keys. Each member key needs its source ID and, when identifiers overlap across types, its type. Keep the localized label as presentation data. If the upstream feed repeats the same member key, deduplicate the exact repeat without suppressing distinct items with identical names.

Test the collision

Create a bundle with an outfit and a back bling that both display “Harbor.” Confirm that both are visible, have distinct destinations, and don't each inherit the bundle price. Then add a second record with the same outfit key. The resulting UI should show two distinct members, not three. Switch languages so the duplicate display names become different, and compare member IDs against the original fixture.

A real catalog such as the SkinRotation cosmetic catalog is suitable for checking how different cosmetic types are labeled.
