Choose Stable Cache Keys for Fortnite Shop Languages

November 24, 2026

A cache key such as shop:today looks harmless until the same worker serves several locales. A German request can warm the key with German labels and an English request can then read the same body. The bug may appear only with a cold cache, when testing accounts visit pages in a different order.

Keep labels and raw offers at the right layer

If the cached response includes localized labels, include locale and rotation ID in the key. If you cache normalized offer IDs and prices without labels, share that cache and localize only the rendered result. Cache failures and empty data only according to the upstream policy. A zero-offer error should never warm the key intended for the day's confirmed rotation.

Check both request orders

Start with empty caches. Request German, then English, and inspect the language and offer labels in both response bodies. Reset the cache and reverse the order. Finally request both locales together at the rotation boundary. Assert each response is attached to the expected locale and rotation ID. The Fortnite Item Shop on SkinRotation gives a live locale reference for the last manual check.
