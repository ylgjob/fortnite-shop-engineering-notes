Fortnite Shop Engineering Notes

Show the Same Fortnite Skin Under Its Old Search Name

November 24, 2026

Someone may remember the name from the first time they saw an outfit. If they type that name into a shop tracker after a rename, an empty search makes them think the outfit has gone missing.

Keep a short list of old names against the cosmetic ID. Search the current name and the aliases, then return each ID once. Put exact matches for current names first. When an old name matched, a small “formerly called …” note can explain why the result appeared.

Try a sample with one current name that is also an alias for a different outfit. Both outfits should appear, with the current-name match first. Then type a name that matches two aliases for one outfit. That should still yield one card. The SkinRotation cosmetic catalog is a place to see what information readers already expect on an outfit page.
