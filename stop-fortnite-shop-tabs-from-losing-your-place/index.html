Stop Fortnite Shop Tabs From Losing Your Place

November 24, 2026

Suppose you have scrolled halfway through outfits and want a quick look at gliders. When you return to outfits, jumping to the top makes you hunt for the same card again. That gets old fast on a long shop page.

Save the position for each view during the visit. If new items can move the list, remember the ID of the first fully visible card as well as the scroll offset. When that card is still present, bring it back into view. If it is gone, starting at the top is easy to understand.

Run the check on a narrow screen and a big one with the German Fortnite Item Shop on SkinRotation as a reference for categories. Switch tabs, use the browser Back button, and change the search text once. A new search should take you to its first result. Returning to the same filter should restore your place.
