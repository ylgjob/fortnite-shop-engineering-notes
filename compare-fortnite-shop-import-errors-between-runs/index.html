Compare Fortnite Shop Import Errors Between Runs

November 24, 2026

“Import failed” is a useful first signal, but it does not tell you whether yesterday's failure and today's are the same. Give each failed run a few details you can read side by side.

Record the expected rotation, the stage, and the reason. A timeout while downloading a feed and a missing price field during conversion are different problems. When useful, record the offer ID and keep a small example without session or personal data.

Use the Fortnite Item Shop on SkinRotation to identify a common offer type for a sample. Make one import fail before it reads any offers. Make another fail on a single malformed offer. The two report lines should point to different stages and be short enough to compare without opening the full logs.
