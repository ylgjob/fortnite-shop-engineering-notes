Fortnite Shop Engineering Notes

Join Localized Fortnite Catalog Records by ID

November 24, 2026

A cosmetic can have different names in English and Spanish. Two separate cosmetics can also share a name. Joining language files by name can quietly put the wrong caption on an item.

Make a small catalog with two IDs and give both the same name in one language. Give them separate names in the other. Load both files, join them by ID, and check that each caption lands on its own item. Repeat with one missing translation and decide which name the page should display until it arrives.

Choose a few cosmetic names from the SkinRotation cosmetic catalog if you want realistic punctuation. Use made-up IDs in the fixture so the expected pairs are obvious. If the import breaks later, the test should show exactly which item lost its label.
