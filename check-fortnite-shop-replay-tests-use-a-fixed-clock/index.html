Check Fortnite Shop Replay Tests Use a Fixed Clock

November 26, 2026

A test that calls the real clock may pass at lunch and fail after midnight. That is especially confusing when the fixture still contains offers for the previous day.

Give the test a clock it can set. Run the same fixture at 23:59 and again at 00:01 in the time zone your archive uses. Keep the snapshot date fixed. Assert which parts of the interface change with time and which parts come from the saved rotation.

Start from a layout such as the SkinRotation Fortnite shop history to decide which label deserves the assertion. For a second test, run the same case with a browser or process set to a different time zone. A test that stays fixed is easier to rerun long after the original rotation.
