Fortnite Shop Engineering Notes

Check the First Public Request After Updating a Fortnite Shop Site

November 24, 2026

A new shop build can look good in the tab you used all morning. That tab may already have images, scripts and a rotation safely stored. A first-time visitor has to fetch all of them.

After a release, open the public page in a private window. Visit the current shop, then a catalog page, and go back. Check the headings, the first few cards, and any failed requests. Repeat in a normal tab that already had the old build open.

Start with the Fortnite Item Shop on SkinRotation as an example of the first address to include in a release check. If only the existing tab breaks, look at which assets it remembers. If only the private window breaks, check the first response and the order in which the page asks for its files.
