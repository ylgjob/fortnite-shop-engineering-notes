Verify Fortnite Catalog Pagination When New Items Arrive

November 24, 2026

An outfit catalog sorted by last seen date needs a tie-breaker. Without one, two items with the same timestamp can trade places between requests. A reader paging forward can see an item twice and miss another.

Use a stable ordering over one result set

Sort by the primary key, such as descending last-seen time, and a stable secondary key, such as the cosmetic ID. A continuation cursor needs both values. If new items may appear between requests, either give the cursor a snapshot version or explain that loading another page uses the current catalog. The first page refresh should make newly inserted entries visible.

Run a six-item comparison

Give four items the same date, set the page size to three, and record the IDs from the first and second pages. Assert that the union contains six unique IDs in the expected order. Insert a new item above the first page after starting the test, then repeat the second-page request with the same cursor. For a snapshot cursor, the earlier view should stay stable. Verify that starting over shows the insertion.

A searchable catalog such as the SkinRotation cosmetic catalog gives you a reference for the manual browsing pass.
