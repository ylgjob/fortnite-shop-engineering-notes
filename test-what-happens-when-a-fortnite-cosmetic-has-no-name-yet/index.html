Test What Happens When a Fortnite Cosmetic Has No Name Yet

November 24, 2026

New catalog entries sometimes arrive before a display name is ready. An unnamed item still needs a stable place in the system. Keep its ID so the catalog can connect it to later updates, but give the visible card a short label such as “Name unavailable”.

Use two unnamed outfits in a fixture, with different IDs. Both should survive the catalog import. An exact name search should not return both just because both share the placeholder. On a debug screen, show the IDs so you can tell which record is missing its name.

Load another snapshot with the real name filled in for just one item. Its page should gain the name without creating a second item or changing the other card. The SkinRotation cosmetic catalog is a useful reference when deciding which fields belong on a normal catalog card.
