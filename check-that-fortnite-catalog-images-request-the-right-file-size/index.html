Check That Fortnite Catalog Images Request the Right File Size

November 26, 2026

A shop can use the same picture everywhere and still cost a phone more data than it needs. The card may be only 160 pixels wide on screen, but the browser is downloading a full-size image for it.

Use browser developer tools to check which image files actually load in a narrow layout. Try the same grid in a wider window and in a high-density device profile. The image hints should describe the width the card really uses, even when the grid changes columns.

Choose a few cards from the SkinRotation cosmetic catalog as layout examples. For a local test, serve two visibly different file sizes and inspect which one the browser selects. Clear the cache between widths so an image already in memory doesn’t confuse the comparison.
