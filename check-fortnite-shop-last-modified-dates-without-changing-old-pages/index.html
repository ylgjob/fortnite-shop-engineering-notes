Check Fortnite Shop Last-Modified Dates Without Changing Old Pages

November 24, 2026

If a shop import runs every day, should it change the Last-Modified date on every page? Start with what actually changed. A saved rotation can stay the same while the current shop gets a new lineup.

Pick an old day and the current shop. Record their headers and save a short copy of the visible offer lists. Run a refresh with a different lineup for today. Fetch both pages again. Today should show the new lineup. The older page can keep its prior Last-Modified value if its content did not change.

Pick a rotation from the SkinRotation Fortnite shop history as the old example. Check the server header separately from the date on the page. A header gives clients information about the response. The date in the heading tells a player which shop they opened.
