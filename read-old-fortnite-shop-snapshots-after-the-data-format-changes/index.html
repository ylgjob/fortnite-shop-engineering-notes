Read Old Fortnite Shop Snapshots After the Data Format Changes

November 24, 2026

A saved rotation may outlive the code that wrote it. If an old archive file stores price as a number and today's code expects a price object, a perfectly good old snapshot can suddenly stop rendering.

Keep one real-looking fixture in each supported shape. Give the reader a small conversion step that turns both versions into the same display fields. Keep the original snapshot as it was saved. That way a converter bug can be fixed without trying to reconstruct the starting data.

Use the earliest available page from the SkinRotation Fortnite shop history as one manual check. Compare the heading, the price label and the offer list before and after you change the reader. If a field was absent on older days, give it a clear empty state. Guessing a value makes the archive harder to trust.
