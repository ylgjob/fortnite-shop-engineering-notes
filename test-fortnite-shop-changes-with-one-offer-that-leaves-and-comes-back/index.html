Test Fortnite Shop Changes With One Offer That Leaves and Comes Back

November 26, 2026

An offer can show up on Monday, disappear Tuesday, and return Wednesday. If the tracker only asks whether it was ever seen before, it can miss the difference between a return and something that stayed on sale.

Make three dated snapshots with the same offer ID on the first and third days. Compare Wednesday with the previous confirmed day. The tracker should recognize the return. Add an offer that appears all three days and another that first appears Wednesday so the fixture covers all three outcomes.

Choose an archive layout from the SkinRotation Fortnite shop history for the manual check. Replace Tuesday with a missing snapshot and rerun the classification. The page should communicate what it can tell without treating a missing day as proof the offer left.
