Check Fortnite Item Totals After a Category Filter

November 24, 2026

An “Outfits (12)” tab sets a simple expectation. When you open it, you should see 12 results. The count can go wrong if the page counts every outfit inside a bundle but displays the bundle as a single card.

Decide what the label counts. If the list displays offers, count displayed offers. If the site has a cosmetic catalog, that count can refer to individual cosmetics. Put a bundle that contains three outfits and a standalone outfit into a test shop. Apply the filter and compare the number beside the tab with the rendered list.

Try an additional text search inside the category. If the tab number stays at the unfiltered total, the page needs to make that clear or give a separate result count. Start with the category layout on the German Fortnite Item Shop on SkinRotation.
