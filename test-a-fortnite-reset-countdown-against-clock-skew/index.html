Test a Fortnite Reset Countdown Against Clock Skew

November 24, 2026

A countdown that reaches zero is often the first thing a player sees when the shop is about to change. If the device clock is four minutes fast, using Date.now() directly can make a tracker declare a reset while the active rotation still has time left.

Calibrate the display against one server response

Record a server timestamp and the local time when the response is received. While the page stays open, advance the displayed server time using elapsed monotonic time. Clamp all negative durations to zero. A countdown hitting zero should switch to “checking the next rotation” until the server confirms a new rotation ID. Resync on return from a long background interval.

A fixture you can reproduce

Set the server time to 23:58 UTC and the next reset to 00:00 UTC. Run once with the device four minutes ahead and once four minutes behind. Both runs should start near two minutes. Suspend the page, advance the fixture by three minutes, and keep the old rotation ID. The countdown should stop at zero, and the offers should stay associated with the last confirmed rotation. Finally return a new ID and check that the view updates once.
