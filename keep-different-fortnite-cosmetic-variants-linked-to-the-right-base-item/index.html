Keep Different Fortnite Cosmetic Variants Linked to the Right Base Item

November 26, 2026

Several styles can belong to one outfit. If you match variants by display name, two outfits with similar titles may end up sharing a variant. The catalog can then show a picture for the wrong item.

In a sample file, give two base items similar names. Give each a different base ID and one variant. Import the file and verify that each variant is attached to its own base. Add a variant with a missing parent and check whether it is held aside until that parent arrives.

Use the SkinRotation cosmetic catalog to see what players expect to find when opening a cosmetic. Check the visible list as well as the stored IDs. A test can pass on the database join and still leave the wrong picture or label on the page.
