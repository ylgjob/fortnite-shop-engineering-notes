Make a Missing Fortnite Shop Image Easy to Report

November 24, 2026

“The picture is broken” leaves a maintainer guessing which card to open. A short report with the item page, the cosmetic name, and the time of the problem usually narrows it down right away.

When you reproduce the issue, note whether the broken image is in the shop grid, the catalog, or both. In the browser's Network panel, find the failed image request. Record its status code and the public image address. A 404 on one image and a blocked image domain across the whole page are different problems.

Use a single cosmetic page from the SkinRotation cosmetic catalog when you report it. There is no need to send cookies, request headers, or a dump of all your browser traffic. Once fixed, check the same page in a fresh tab so a local cache does not hide the result.
