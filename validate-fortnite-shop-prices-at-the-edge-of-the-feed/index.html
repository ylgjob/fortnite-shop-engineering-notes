Validate Fortnite Shop Prices at the Edge of the Feed

November 26, 2026

The feed may send a price as 800 in one response and as “800” in another. It may leave the price blank for an item with no separate offer. Letting all these values fall through to a subtraction or a sort makes the result hard to trust.

Pick which shapes the importer accepts. A numeric string can be converted if the feed documents it. Empty strings, absent fields and a real zero should keep different meanings. Reject values with a number followed by unknown text instead of guessing the amount.

Use the Fortnite Item Shop on SkinRotation as a reference for the currency a player actually sees. Include 0, a blank field and a plainly malformed string in a fixture. The normalized outputs should make it obvious which offers have a known price.
