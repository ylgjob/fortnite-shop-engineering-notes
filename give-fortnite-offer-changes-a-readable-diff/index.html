Give Fortnite Offer Changes a Readable Diff

November 24, 2026

A raw data diff is hard to read when the names are long and each offer has lots of fields. Start by lining up offers using the IDs in both snapshots. Print three short sections for offers added, offers removed, and offers that changed while staying in the shop.

For each changed offer, show only the fields that are different. An example might read “Price: 1,200 → 1,000” on one line and “Removed: back bling” on the next. Leave image URL changes out of a player-facing report unless the image itself is the problem you are tracking.

Try it with two days from the SkinRotation Fortnite shop history. A hand-written fixture is enough for the code test. Give it one new offer, one removed offer, and one price-only change. A maintainer should be able to count each group without opening the JSON.
