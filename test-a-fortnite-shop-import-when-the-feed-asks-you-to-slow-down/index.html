Test a Fortnite Shop Import When the Feed Asks You to Slow Down

November 24, 2026

A shop feed can ask a client to slow down. If a scheduled job retries immediately, several copies of the job may start hitting the same feed just as it is trying to recover.

In a test, have the first fetch return HTTP 429 with Retry-After set to sixty seconds. Advance a test clock to fifty-nine seconds and check that no new call goes out. Advance it again and allow one retry. A second copy of the scheduled job should see the wait and should not start making its own requests.

Open the Fortnite Item Shop on SkinRotation to see the sort of page players may be using while a background job waits. Keep serving your saved rotation during the pause. If you display an update time, show when the data was last fetched successfully.
